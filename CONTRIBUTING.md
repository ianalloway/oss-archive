# Contributing to Portfolio Ship Week

Thank you for your interest in improving the **Portfolio Ship Week** skill! We welcome contributions that help make the portfolio launch process smoother and more effective for everyone.

## 🛠️ How to Contribute

### 1. Add New Templates
If you have a great template for a specific framework (e.g., Next.js, Vue, Svelte) or a new type of static file (e.g., `robots.txt`, `sitemap.xml`), please add it to the `templates/` directory.

### 2. Improve the Workflow
If you find a more efficient way to handle DNS fixes, SEO integration, or outreach, please update the `SKILL.md` file with your improvements.

### 3. Report Issues
If you encounter any bugs or have suggestions for new features, please open an issue in this repository.

## 📝 Contribution Guidelines

- **Keep it Concise**: Skills should be lean and focused. Avoid adding unnecessary complexity.
- **Use Templates**: Prefer using `.template` files for any boilerplate code.
- **Test Your Changes**: If you add a script or a template, ensure it works as expected in a real-world scenario.
- **Follow the Format**: Maintain the existing structure of `SKILL.md` and the repository.

## 🚀 Getting Started

1. **Fork the repository**.
2. **Create a new branch** for your changes.
3. **Make your improvements**.
4. **Submit a pull request** with a clear description of what you've changed.

We appreciate your help in making this skill better for the community!
