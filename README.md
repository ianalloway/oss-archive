# oss-archive

Snapshots of Ian’s **archived** public GitHub repositories.

- **Layout:** one branch per former repo: `archive/<repository-name>` (tree = that repo’s default branch at migration time).
- **Browse:** [All branches](https://github.com/ianalloway/oss-archive/branches/all)
- **Original repos** were set to **Archived** on GitHub after their contents were pushed here; history is preserved on each `archive/*` branch.
