# Portfolio Ship Week Skill

A comprehensive workflow for launching and optimizing personal portfolios, including DNS fixes, SEO infrastructure, and job search outreach.

## 🚀 Overview

This skill is designed to help Manus agents (and users) navigate the final, critical steps of a portfolio launch. It transforms a "finished" project into a "shipped" professional presence.

## 🛠️ Key Features

- **DNS Diagnosis**: Step-by-step workflow to identify and resolve domain resolution issues.
- **SEO Infrastructure**: Reusable React components and templates for meta tags, Open Graph, and structured data.
- **GitHub Integration**: Best practices for applying fixes directly to portfolio repositories.
- **Outreach Strategy**: Tailored email drafts and checklists for high-priority job applications.

## 📂 Repository Structure

- `SKILL.md`: The core instruction set for the Manus agent.
- `templates/SEO.tsx.template`: A React component for managing page metadata.
- `templates/DNS_FIX_GUIDE.md.template`: A guide for users to fix their domain settings.

## 📖 How to Use

1. **Clone this repository** into your Manus environment's `skills/` directory.
2. **Ask Manus** to "Help me launch my portfolio using the portfolio-ship-week skill."
3. **Follow the workflow** to fix your DNS, update your SEO, and send your outreach emails.
